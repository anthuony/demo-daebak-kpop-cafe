# Daebak Kpop Café · Demo comercial

Propuesta visual de una página, con identidad pastel basada en el logo real, fotografías oficiales, menú por categorías, galería ampliable, mapa y contacto.

Los datos y las fuentes se documentan en `SOURCES.md`. No se incluyen precios ni eventos sin confirmar.

## Desarrollo

Instalar las dependencias según el archivo pnpm-lock.yaml. Ejecutar el script dev para desarrollo y build para producción. La configuración de Sites se mantiene en .openai/hosting.json.

La demo se crea como un sitio privado y no indexable.
